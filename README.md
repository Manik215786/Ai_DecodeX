# Ai_DecodeX
AI-powered Exam Strategist that maps past paper frequency against syllabus, ranks high-yield topics, and generates smart study plans for students. 🎓🚀
## Project Overview

Students often struggle to identify which topics are actually important across years of question papers. ExamAI solves this by using AI to analyze multiple years of PDFs and cross-referencing them with the official syllabus to find coverage gaps and high-frequency patterns. 

## Key

FeaturesMulti-Paper Trend Analysis: Scans multiple years of PDF question papers to find topic repetition.  Syllabus Gap Detection: Identifies topics mentioned in the syllabus but never asked in exams (the "Surprise" zones).  Priority Scoring (1-100): Ranks topics using a custom engine based on frequency and syllabus weightage.  Smart Study Planner: Generates a day-wise study schedule prioritized by topic importance.  AI Practice Mode: Suggests potential questions based on historical phrasing styles. 

## Tech StackFrontend:

Streamlit (Python-based Web UI) 

LLM Engine: Groq (Llama 3.3 70B) for ultra-fast reasoning  

Extraction: pdfplumber for high-accuracy text retrieval  

Processing: Structured JSON parsing for data visualization
